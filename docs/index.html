NeurIPS 2025 & ICML 2026 · Pure Rust Port

Sub-1-Bit LLM Compression Without Python

littlebit-rs is a pure-Rust implementation of SamsungLabs/LittleBit and LittleBit-2 Joint-ITQ built on Candle and faer — covering low-rank SVD + Joint-ITQ initialization, Knowledge Distillation QAT, upstream bit-identical i32 safetensors packing, and direct 1-bit packed inference.

  • 0.1–1.0 bpw Sub-1-bit latent factorization
  • 6 Families Llama, Qwen2/3, Phi-3/4, Gemma 2/3, OPT
  • 59 Tests Upstream & community audit parity
  • 0 Unsafe Workspace forbids unsafe_code

CLI Quickstart

Accepts both Rust-native kebab-case (--use-itq True) and upstream underscored flags (--use_itq True).

Build (CPU, Accelerate, Metal, or CUDA)

# Default CPU build (faer multi-threaded BLAS/SVD + rayon)
cargo build --release

# Apple Silicon Accelerate / Metal GPU / NVIDIA CUDA
cargo build --release --features accelerate
cargo build --release --features metal
cargo build --release --features cuda

Post-Training Quantization with LittleBit-2 Joint-ITQ & Mixed Bits

cargo run --release -p littlebit-cli -- quantize \
  --model-id meta-llama/Llama-2-7b-hf \
  --save-dir ./outputs/Llama-2-7b-LittleBit-2 \
  --quant-func SmoothSign \
  --eff-bit 1.0 \
  --eff-bit-layers "0-3:2.0" \
  --residual True \
  --kv-factor 1.0 \
  --min-split-dim 8 \
  --use-itq True \
  --itq-n-iter 50

Knowledge Distillation QAT Training

cargo run --release -p littlebit-cli -- train \
  --model-id meta-llama/Llama-2-7b-hf \
  --dataset c4_wiki \
  --save-dir ./outputs/Llama-2-7b-LittleBit-2 \
  --num-train-epochs 5.0 \
  --per-device-train-batch-size 4 \
  --lr 4e-5 \
  --warmup-ratio 0.02 \
  --quant-func SmoothSign \
  --residual True \
  --eff-bit 1.0 \
  --l2l-loss-scale 10.0 \
  --use-itq True

Inspect, Evaluate (1-Bit Packed), & Generate

# Header-only layer & compression ratio inspection (no full weight load)
cargo run --release -p littlebit-cli -- inspect --model-id ./outputs/Llama-2-7b-LittleBit-2

# Packed 1-bit perplexity evaluation
cargo run --release -p littlebit-cli -- eval \
  --model-id ./outputs/Llama-2-7b-LittleBit-2 \
  --packed-inference --seqlen 2048 --ppl-task wikitext2

# Autoregressive generation
cargo run --release -p littlebit-cli -- generate \
  --model-id ./outputs/Llama-2-7b-LittleBit-2 \
  --packed-inference --prompt "Sub-1-bit LLM compression works by" --max-tokens 64

Upstream Parity & Community Audits

  • Bit-Exact 1-Bit Unpacking (Issue #21 / PR #22 & Deployment Audit): Uses the exact LSB-first right-shift decoder ((word >> bit) & 1) and validates all 2,010 deterministic test cases across widths [1, 7, 8, 31, 32, 33, 64] against an independent shift-free byte-table reference decoder, plus full SmoothSign + residual checkpoint round-trips with bitwise-equal F32 outputs.
  • FP16 Overflow Protection (Issue #24 & Volta Bench): Guards intermediate binary matmuls via exact power-of-two scaling (pow2_at_least) on GPU paths and F32 accumulation on CPU, keeping long-summation projections (e.g., in_features = 2048) free of NaN/Inf.
  • Mixed-Bit Patching & Warm-Start: Supports --eff-bit-layers (e.g. "0-7,27:2.0") persisted in littlebit_config.json and config.json, plus warm_start_from_binarized(latent_mag) for resuming QAT from finished packed models.
  • Zero Unsafe & Clean Tooling: Workspace enforces unsafe_code = "forbid", passes cargo fmt --check, cargo clippy --all-targets -- -D warnings, 59 tests across all crates, and RUSTDOCFLAGS="-D warnings" cargo doc.
